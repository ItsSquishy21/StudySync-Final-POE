# StudySync – Student Productivity App

## About the Application

StudySync is an Android student productivity application developed to help students organise their academic responsibilities, manage study materials and monitor their learning progress.

The application brings together task management, study scheduling, reminders and study material storage in one convenient platform.

## Features

- **User Authentication:** Register and log in using an email address and password.
- **Dashboard:** View academic activity and task progress.
- **Task Management:** Create, manage and complete academic tasks.
- **Task Priorities:** Organise tasks according to their importance.
- **Study Materials:** Upload, store and access learning resources.
- **Timetable:** Organise study sessions and academic activities.
- **Reminders:** Set reminders to help keep track of study sessions.
- **Profile Management:** Manage personal account information.
- **Application Settings:** Customise the application, including its appearance.
- **Progress Tracking:** Monitor completed tasks and academic progress.

## Technologies Used

- Kotlin
- Android Studio
- Jetpack Compose
- Firebase Authentication
- Cloud Firestore
- Cloud Storage
- Android SharedPreferences
- Android Keystore

## Installation and Setup

1. Clone or download the StudySync repository.
2. Open the project using Android Studio.
3. Allow Gradle to sync and download the required dependencies.
4. Configure the Firebase project and add your own `google-services.json` file.
5. Configure any required cloud storage credentials.
6. Connect an Android device or start an emulator.
7. Build and run the application.
